# UX心理学 適用ガイド（本アプリ固有）

> 各法則の説明は共通リファレンスを参照: `~/.claude/docs/ux_psychology_laws.md`
> 本ドキュメントは「Web小説更新通知アプリ」への具体的な適用方針のみを記載する。

---

## 1. Desktop Triage（仕分けUI）

| 適用法則 | 適用内容 |
|---------|---------|
| スキューモーフィズム | カードに紙の質感・影。金/銀/事務トレー・ゴミ箱は実オフィス用品を模したビジュアル |
| ピーク・エンドの法則 | トレー着地時に光る演出＋Haptics。★3は金色パーティクル。全仕分け完了時に達成演出 |
| 認知負荷の軽減 | 操作は4方向スワイプのみ。カード情報は最小限。Magnetic Guideで方向を明示 |
| 決断疲れの防止 | 1セッション最大20枚。スキップ（スタック末尾に戻す）を用意。前回スタンプ情報をヒント表示 |
| 授かり効果 | Snap Back（トレーから引き戻し）。ゴミ箱はアーカイブ30日保持 |

## 2. 3段階深度ログ（スタンプ → タグ → 布教カード）

| 適用法則 | 適用内容 |
|---------|---------|
| 段階的要請 | L1: スタンプ1タップ → L2:「タグも付ける？」控えめ提案 → L3:「布教カード作ってみない？」 |
| 段階的開示 | タグ機能はスタンプ3回後に提案。布教カードはタグ5個以上で解放 |
| 誘惑の結びつけ | スタンプ直後にエフェクト再生（🔥炎、😭雨）。布教カード生成→SNS共有と直結 |
| 労働の錯覚 | 布教カード生成時に合成アニメーション（1〜2秒の演出を挟む） |

## 3. フィード・本棚

| 適用法則 | 適用内容 |
|---------|---------|
| 系列位置効果 | フィード先頭に熱量最高の作品。末尾に完結通知。中間にアフィリエイト広告 |
| 損失回避 | 未読話数を赤バッジ表示。長期未読に「未読が○話溜まっています」通知 |
| 好奇心ギャップ | 更新通知に最新話タイトルを表示、内容は非表示 |
| バナー・ブラインドネス回避 | Amazonアフィは「書籍化されています」情報カードとして同UIで表示 |
| 選択的注意 | サイト種別アイコン色分け。未読/更新/完結のステータス視覚的差別化 |

## 4. オンボーディング

| 適用法則 | 適用内容 |
|---------|---------|
| 反応型オンボーディング | 初回チュートリアルなし。ブックマーク登録だけガイド→初Triage時にスワイプガイド→初スタンプ時に説明 |
| デフォルト効果 | 通知ON、テーマ「システム連動」、並び順「熱量順」をデフォルト |
| 期待バイアス | App Storeで「秒速管理」「ワンタップ読了」を約束し、初回体験で実現 |

## 5. 継続利用

| 適用法則 | 適用内容 |
|---------|---------|
| 変動型報酬 | 更新通知自体が変動報酬。スマート・キューの並び順が毎回変化 |
| 目標勾配効果 | カードスタック残枚数表示。未読カウントダウン。月間読了グラフで「あと○話で先月超え」 |
| ツァイガルニク効果 | 再起動時「未仕分け○枚」表示。読みかけ作品を目立つ位置に配置 |
| ゲーミフィケーション | 読了数バッジ（控えめ）。月間統計の自己記録更新表示 |
| サンクコスト効果 | 詳細画面でスタンプ・タグ・メモの蓄積データ可視化。削除時に「○件のデータが〜」と表示 |

## 6. 全体UIデザイン

| 適用法則 | 適用内容 |
|---------|---------|
| 美的ユーザビリティ効果 | 一貫したデザインシステム。60fpsアニメーション。ダークモード専用デザイン |
| 視覚的階層 | タイトル/未読数/スタンプを最大・目立つ色。作者名/サイト/日時はサブテキスト |
| ビジュアル・アンカー | 金トレーに光沢アニメ。未読バッジ赤統一。Share Extension成功時の緑フラッシュ |
| ドハティの閾値 | スワイプ→着地 0.3秒以内。スケルトンスクリーン即座表示。楽観的更新 |
| ユーザー歓喜効果 | ★3殿堂入り金パーティクル。スタンプ各種エフェクト。全仕分け完了時の達成アニメ |
| 親近性バイアス | iOS標準UIパターン準拠。独自UIはDesktop Triageのみ |
| ナッジ効果 | 未評価作品に「★?」アイコン。新カード時バッジ更新 |
